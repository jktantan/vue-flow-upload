# AvatarUpload

`AvatarUpload` — компонент одного аватара: после выбора изображение обрезается в пропорции 1:1, а результат сохраняется как изображение 512 × 512. Компонент отображает только первый элемент списка `v-model`. Круг — это визуальная маска карточки и рамки обрезки, а на сервер файл всегда уходит квадратным.

| Prop               | Тип                                     | По умолчанию  | Описание                                                                                     |
| ------------------ | --------------------------------------- | ------------- | -------------------------------------------------------------------------------------------- |
| `v-model`          | `UploadUserFile[]`                      | —             | Список аватара из одного элемента; компонент отображает только первый.                        |
| `belong-id`        | `string \| number`                      | обязательно   | Идентификатор бизнес-записи; записывается в JSON `data.belongId` запроса загрузки.             |
| `belong-type`      | `string`                                | `default`     | Тип бизнес-записи; записывается в JSON `data.belongType`.                                      |
| `extra`            | `Record<string, unknown>`               | —             | Объект расширенных атрибутов; записывается в JSON `data.extra`.                                |
| `action`           | `string`                                | —             | Встроенный интерфейс первой загрузки.                                                         |
| `update-action`    | `string`                                | —             | PUT-интерфейс замены существующего аватара; поддерживает плейсхолдер `{fileId}`.               |
| `delete-action`    | `string`                                | —             | Встроенный интерфейс удаления существующего аватара.                                           |
| `transport`        | `UploadTransport`                       | —             | Пользовательский адаптер загрузки и удаления.                                                  |
| `data`             | `UploadData`                            | —             | Бизнес-данные, отправляемые с каждой загрузкой; допустима асинхронная фабрика.                 |
| `accept`           | `string \| string[]`                    | —             | Допустимые типы изображений.                                                                   |
| `max-size`         | `number`                                | —             | Максимальный размер исходного изображения в байтах.                                            |
| `width` / `height` | `string \| number`                      | `300`         | Размер карточки аватара; числа трактуются как пиксели.                                         |
| `disabled`         | `boolean`                               | `false`       | Отключает всё взаимодействие.                                                                  |
| `read-only`        | `boolean`                               | `false`       | Запрещает выбор, замену и удаление; при включённом `preview` просмотр остаётся доступным.      |
| `shape`            | `'square' \| 'circle'`                  | `'square'`    | Визуальный контур карточки и рамки обрезки; для круга рекомендуются равные ширина и высота.    |
| `preview`          | `boolean`                               | `true`        | Разрешён ли просмотр текущего аватара.                                                         |
| `permissions`      | `UploadPermissions`                     | `{}`          | Пооперационные ограничения выбора, удаления и просмотра; незаполненные операции разрешены.      |
| `before-upload`    | `(file) => boolean \| Promise<boolean>` | —             | Вызывается после клиентской проверки и до открытия обрезчика; `false` или reject отменяет.     |
| `locale`           | `string`                                | как у хоста   | Язык встроенных подписей компонента.                                                           |

Первая загрузка идёт через `action` или `transport.uploadFile`. Если аватар уже есть и настроен `update-action`, компонент отправляет `PUT` с двумя multipart-полями `file` и `fileId`; первый успешный ответ обязан вернуть `fileId`.

`belong-id` обязателен, `belong-type` по умолчанию равен `default`. Оба поля и `extra` объединяются в multipart-поле JSON `data` и означают соответственно идентификатор бизнес-записи, её тип и расширенные атрибуты; запрос обновления через `update-action` передаёт это поле так же.

Для режима только чтения используйте `read-only`: он блокирует выбор, замену и удаление, но не отключает просмотр:

```vue
<AvatarUpload v-model="avatarFiles" belong-id="profile-1" read-only shape="circle" />
```

## События

| Событие             | Аргументы          | Когда отправляется                                                                       |
| ------------------- | ------------------ | ---------------------------------------------------------------------------------------- |
| `update:modelValue` | `(files)`          | Управляемый список обновился, передаётся нормализованный полный список.                   |
| `change`            | `(file, files)`    | После изменения локальной записи аватара отправляются текущая запись и полный список.     |
| `success`           | `(file, response)` | После подтверждения загрузки сервером отправляются запись и ответ.                        |
| `error`             | `(file, error)`    | Ошибка загрузки; `file` — обрезанный `File`, `error` — экземпляр `Error`.                 |
| `remove`            | `(file)`           | После успешного удаления аватара отправляется удалённая запись.                           |

Демонстрацию можно открыть сразу: [ДЕМО загрузки аватара](/ru/demos/avatar-upload).
