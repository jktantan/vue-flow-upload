# FlowUpload

`FlowUpload` предназначен для загрузки нескольких файлов. `action` — сокращённая запись обычной загрузки для встроенного `transport` на XHR; если передан `transport`, хост полностью контролирует протокол запросов и `transport` имеет приоритет.

## Основные props

| Prop                 | Тип                                         | По умолчанию      | Описание                                                                                                                                                          |
| -------------------- | ------------------------------------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `v-model`            | `UploadUserFile[]`                          | —                 | Управляемый список файлов, внешний источник истины.                                                                                                               |
| `default-file-list`  | `UploadUserFile[]`                          | `[]`              | Начальный список файлов для неуправляемого режима.                                                                                                                |
| `belong-id`          | `string \| number`                          | обязательно       | Идентификатор бизнес-записи; записывается в JSON `data.belongId` запроса загрузки.                                                                                |
| `belong-type`        | `string`                                    | `default`         | Тип бизнес-записи; записывается в JSON `data.belongType`.                                                                                                         |
| `extra`              | `Record<string, unknown>`                   | —                 | Объект расширенных атрибутов; записывается в JSON `data.extra`. query-transport использует его для сопоставления в конкретном проекте, а глубокое изменение перезагружает список с первой страницы. |
| `action`             | `string`                                    | —                 | Сокращённая запись URL обычной загрузки для встроенного `transport` на XHR.                                                                                        |
| `create-action`      | `string`                                    | —                 | Интерфейс создания или подтверждения серверной записи файла перед загрузкой; возвращает `fileId`.                                                                 |
| `delete-action`      | `string`                                    | —                 | Интерфейс идемпотентного удаления файла и его сессий загрузки по `fileId`.                                                                                         |
| `method`             | `'POST' \| 'PUT'`                           | `'POST'`          | HTTP-метод встроенной обычной загрузки.                                                                                                                           |
| `transport`          | `UploadTransport`                           | —                 | Адаптер протокола загрузки; подойдёт любой HTTP-клиент или SDK прямой загрузки.                                                                                    |
| `download-transport` | `DownloadTransport`                         | —                 | Адаптер скачивания одного файла и создания серверных задач архивации.                                                                                              |
| `query-transport`    | `FileQueryTransport`                        | —                 | Адаптер запроса списка файлов; после передачи компонент умеет загружать список, фильтровать и листать его.                                                          |
| `query-on-mount`     | `boolean`                                   | `true`            | Загружать ли список файлов через адаптер запроса при монтировании.                                                                                                 |
| `data`               | `UploadData`                                | —                 | Бизнес-данные, отправляемые с каждой загрузкой; допустима асинхронная фабрика. `belong-id`, `belong-type` и `extra` перекрывают одноимённые поля.                   |
| `file-field-name`    | `string`                                    | `'file'`          | Имя поля бинарного файла в multipart.                                                                                                                             |
| `data-field-name`    | `string`                                    | `'data'`          | Имя поля JSON-данных в multipart.                                                                                                                                 |
| `accept`             | `string \| string[]`                        | —                 | Фильтр по расширениям или MIME-типам.                                                                                                                              |
| `max-size`           | `number`                                    | —                 | Максимальный размер одного файла в байтах.                                                                                                                        |
| `max-count`          | `number`                                    | без ограничений  | Максимальное число файлов в списке; лишние возвращаются событием `exceed`.                                                                                          |
| `multiple`           | `boolean`                                   | `true`            | Разрешён ли множественный выбор.                                                                                                                                   |
| `auto-upload`        | `boolean`                                   | `true`            | Начинать ли загрузку сразу после выбора; если выключено, очередь запускает метод `submit()`.                                                                        |
| `before-upload`      | `(file) => boolean \| Promise<boolean>`     | —                 | Вызывается после клиентской проверки и до постановки задачи; `false` или reject отклоняет файл.                                                                     |
| `before-remove`      | `(file, files) => boolean \| Promise<boolean>` | —              | Вызывается перед удалением; `false` или reject сохраняет файл.                                                                                                     |

## Props для больших файлов

| Prop                      | Единица | По умолчанию | Описание                                                |
| ------------------------- | ------- | ------------ | ------------------------------------------------------- |
| `normal-upload-threshold` | байты   | `10 MiB`     | Файлы больше этого размера идут по пути частей.         |
| `chunk-size`              | байты   | `1 MiB`      | Размер одной части.                                     |
| `chunk-concurrency`       | шт.     | `3`          | Число частей одного файла, загружаемых параллельно.     |
| `max-concurrent-files`    | шт.     | `2`          | Число файлов, загружаемых одновременно.                 |
| `max-concurrent-requests` | шт.     | `6`          | Максимум запросов, общий для всех файлов.               |
| `retry-count`             | раз     | `3`          | Дополнительные попытки для повторяемой ошибки.          |
| `retry-base-delay`        | мс      | `500`        | Начальная задержка экспоненциальной паузы.              |
| `resume`                  | —       | `true`       | Восстанавливать ли неистёкшую сессию частей.            |
| `instant-upload`          | —       | `true`       | Вычислять ли SHA-256 и проверять мгновенную загрузку.    |

## Диагностическое поле состояния файла

Когда файлу нужно вычислить SHA-256, поле `hashStrategy` соответствующего элемента `UploadFileItem` в `v-model` фиксирует реализацию, завершившую расчёт: `web-crypto` (нативный API браузера), `wasm` (`hash-wasm`) или `local` (локальный фолбэк на TypeScript). Поле служит только для диагностики и не влияет ни на протокол сервера, ни на значение дайджеста.

## Слоты и методы экземпляра

`#tip` отображается под областью выбора; `#file` полностью заменяет строку одного файла, его атрибуты: `file`, `remove`, `preview`, `download`, `pause`, `resume`, `retry`.

Экземпляр компонента предоставляет следующие методы:

| Метод                        | Описание                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `submit()`                   | Запускает загрузку всех файлов в состоянии `idle`.                                          |
| `abort(file?)`               | Приостанавливает один файл; без аргумента — все файлы.                                      |
| `pause(uid)` / `resume(uid)` | Приостановить или продолжить указанный файл.                                                |
| `retry(uid)`                 | Повторно загрузить указанный файл.                                                          |
| `remove(uid \| file)`        | Удаляет указанный файл, при необходимости сначала показывая подтверждение; возвращает, удалён ли файл. |
| `clear()` / `clearFiles()`   | Очищает список файлов и освобождает связанные ресурсы.                                       |
| `handleStart(file)`          | Проводит один `File` через полный путь выбора, проверки и постановки в очередь.              |
| `handleRemove(uid \| file)`  | Удобная обёртка над `remove`, принимает и полный элемент файла.                              |
| `download(uid)`              | Скачивает один постоянный файл.                                                             |
| `downloadSelected(uids)`     | Создаёт серверную задачу архивации для указанных файлов и скачивает её.                      |
| `downloadAll()`              | Скачивает все файлы по `all-download-scope` или по текущему списку.                          |
| `cancelArchive(taskId)`      | Отменяет незавершённую задачу архивации.                                                    |
| `refreshQuery()`             | Немедленно повторяет запрос списка по текущему `extra` и пагинации.                          |

Полный пример ручного вызова приведён в [ДЕМО ручной загрузки](/ru/demos/manual-upload).
