# Частые сценарии

## Управляемый список файлов

После передачи `v-model` внешний список становится источником истины. Компонент не изменяет prop напрямую, а возвращает новый список через `update:modelValue`.

```vue
<FlowUpload v-model="files" belong-id="order-1" action="/files" />
```

## Ограничение типа, размера и количества

```vue
<FlowUpload
  v-model="files"
  belong-id="order-1"
  action="/files"
  accept="image/*,.pdf"
  :max-size="20 * 1024 * 1024"
  :max-count="5"
  drag
/>
```

`accept` — это подсказка для выбора файлов в браузере; сервер всё равно должен проверять тип и размер.

## Отключение автозагрузки

При `auto-upload="false"` выбор файлов не запускает запрос сразу. Очередь запускается методом экземпляра `submit()`, см. [ДЕМО ручной загрузки](/ru/demos/manual-upload).

## Аватары

`AvatarUpload` рассчитан на один аватар: изображение сначала обрезается в пропорции 1:1, затем вызывается интерфейс загрузки. См. [ДЕМО загрузки аватара](/ru/demos/avatar-upload).
